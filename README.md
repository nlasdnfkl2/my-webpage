## 1. 프로젝트 개요

본 프로젝트는 정보를 수집하고 분류하는 문헌정보학적 사고와 실무적 가치를 창출하는 상업정보학적 역량을 결합하여, **기획안 · 시각 그래픽 · 학술 논문 · 브라우저 기반 실용 웹 도구**를 하나의 아카이브로 통합한 웹 포트폴리오입니다.

모든 웹 애플리케이션은 별도의 복잡한 서버 구축 없이 정적 웹(GitHub Pages)과 Google Apps Script, Google Sheets DB, Gemini AI API를 연동하여 수업 현장과 학급 경영, 일상생활에서 즉시 활용할 수 있도록 설계되었습니다.

## 2. 포트폴리오 웹사이트 주요 기능 (`index.html`)

* **네오 브루탈리즘(Neo-Brutalism) UI/UX**: 모눈종이 그리드 배경, 굵은 외곽선(`3px~4px`), 솔리드 섀도우, 고대비 포인트 컬러를 적용하여 직관적이고 경쾌한 아카이브 경험을 제공합니다.

* **실시간 라이브 미리보기(Live Preview)**: 24종의 웹 앱 카드를 400% 축소 비율의 실시간 `iframe`으로 렌더링하여 접속 즉시 실제 화면 구성을 확인할 수 있습니다. (하위 미리보기 창 내부 오디오 자동 차단 로직 적용)

* **카테고리 필터링 및 실시간 검색**: 전체 24종 프로젝트를 4개 핵심 분야(AI·시각화, 교육·교구, 시트 연동·DB, 유틸리티·생활)로 분류하고, `/` 단축키 및 실시간 키워드 검색으로 빠르게 탐색할 수 있습니다.

* **모바일 QR코드 즉시 연결**: 모든 개별 앱 카드와 상단 헤더에 동적 QR코드 생성 모달(`QRCode.js`)을 탑재하여 스마트폰 카메라 스캔만으로 모바일 화면 및 PWA 버전에 즉시 접속할 수 있습니다.

* **인터랙티브 디자인 뷰어**: 카드뉴스 좌우 캐러셀, 앞·뒷면 비교 3D 플립 카드, 그룹 단위 이미지 확대 라이트박스, 학술 소논문 PDF 본문 임베드 뷰어를 지원합니다.

## 4. 기술 스택 (Tech Stack)

* **Frontend**: HTML5, CSS3 (Custom Properties, Grid/Flexbox, Responsive Media Queries), Vanilla JavaScript (ES6+)

* **Backend & Database**: Google Apps Script (Web App REST API), Google Sheets (실시간 관계형 시트 DB)

* **AI & Libraries**: Google Gemini API, SheetJS (`xlsx` 엑셀 내보내기), QRCode.js, Tesseract.js (OCR), Three.js / Canvas 2D

* **Deployment**: GitHub Pages (`https://nlasdnfkl2.github.io/my-webpage/`) 및 Progressive Web App (PWA)
